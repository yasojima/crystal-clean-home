よくあるご質問

どの清掃メニューを選べばよいか分かりません。

気になる場所や汚れの状態をお聞かせください。設備やご希望を確認し、必要な清掃範囲とメニューをご案内します。

すべての汚れを落とせますか？

素材の変色や劣化、設備の状態によっては、落としきれない汚れがあります。対応できる範囲と仕上がりの見込みを事前にご説明します。

小さな子どもやペットがいても相談できますか？

ご相談いただけます。生活環境やご心配な点を伺い、洗剤の選定、作業場所への立ち入り、換気など、作業の進め方をご案内します。

作業中に追加の確認が必要になった場合は？

確認事項をご説明し、お客様と相談したうえで対応します。作業内容や料金に関わることを、ご案内せず進めることは避けます。

清掃後のお手入れも教えてもらえますか？

清掃した箇所と日頃のお手入れについてご説明します。気になる点やご質問にも丁寧にお答えします。

大切な住まいに、確かな手仕事と、誠実な説明を。
ご相談から作業後まで、丁寧に向き合ってまいります。
