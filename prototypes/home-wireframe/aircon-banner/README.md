## 所有元

- `assets/banner-a-raster.png`、`banner-b-raster.png`、`banner-c-raster.png`：今回の広告画像３点。見出し・価格・CTA・条件の文字を含む。
- `image-generation.json`：built-in image_genの使用モード、参考画像の役割、３案の最終生成プロンプトとBの条件位置修正プロンプト、生成時の価格スナップショット。
- `build.py`：既存料金正本から価格を取得し、比較画面、HOME内比較、設計説明とメタデータを生成する。画像生成時の金額と現行正本が違う場合はビルドを停止する。
- `banner.css`：比較画面と画像表示だけのCSS。広告の文字組みは画像内。
- `context.js`：HOME内比較画面のA/B/C切替。
- `assets/aircon-pair.png`：３案の人物なし・文字なしの商品参照素材。
- `index.html`、`context.html`、`build-info.json`：ビルド成果物。

料金正本は `source/service-pages/catalogue.json: products.1`、読み出しは既存の `tools/build_cart_catalogue.py: prices`。１台13,200円、２台以上は１台11,000円、１台あたり2,200円・２台合計4,400円お得、２台合計22,000円。共通条件は「壁掛けタイプ（お掃除機能なし）／同時に２台以上のご注文時／税込」です。他社名・電話・期間・プレゼント・女性スタッフ対応等は引き継ぎません。

## 今回の画像提案とSEO実装の区別

今回は文字を含む画像を優先してデザイン提案しています。見出し・料金・条件・CTAを可視のHTML文字へ分離する実装は未実施です。altと比較画面の説明は用意していますが、これを当初希望のHTML文字実装が完了した証拠とは扱いません。

HTML/CSSへ分離する場合は、背景・エアコン・装飾を文字なし素材、見出し・価格・CTA・条件をHTMLとする設計を３案共通で示しています。確認済みの公式資料は次のとおりです。

## ３案の設計説明

３案は文字を含む画像デザイン案です。採用する案と、本編への反映・SEO向けの文字分離は未決定です。

### A案：4,400円お得！を押し出す

- **狙い**：お得額が一目で入る、最も販促感の強い案。青い4,400とオレンジのお得！を、縁取り・傾き・立体感で一つの文字組みにします。
- **レイアウト**：左にカテゴリ、２台まとめて、大きな4,400円お得！、補足、青いCTA、条件。右に上下へずらした２台と水・風の演出。
- **配色**：黄色×ロイヤルブルーを主役に、お得！だけをオレンジ。白い縁取りと背景の放射・端のドットで文字を浮かせます。
- **メインコピー**：２台まとめて 4,400円お得！
- **価格の見せ方**：4,400円を最大の文字組みとし、１台あたり2,200円お得は白い筆風の帯に小さく添えます。
- **CTA**：料金・サービスを見る。青い立体ピル形、白い丸の中に右矢印。
- **HTML/CSS構造**：今回は文字を含む画像デザイン案。HTML/CSSで実装する場合は、左の見出し・数字・条件・CTAをHTMLにし、背景と右のエアコンを文字なし画像へ分離する。分離実装は未実施。

- **狙い**：１台あたりの料金理解を優先する案。青い見出しの下にオレンジの11,000を置き、価格だけが最も強く目に入る構成にします。

- **配色**：白×水色×青の清潔感に、オレンジの価格と黄色の単位ラベル。価格の縁と影、CTAのハイライトに細部の差を付けます。
- **メインコピー**：２台以上なら、１台あたり11,000円（税込）
- **価格の見せ方**：11,000を最大、円と税込は横に小さく。２台合計22,000円（税込）は下の細い行へ分けます。
- **CTA**：料金・サービスを見る。青い立体ピル形、白い丸の中に右矢印。
- **HTML/CSS構造**：今回は文字を含む画像デザイン案。HTML/CSSで実装する場合は、左の見出し・数字・条件・CTAをHTMLにし、背景と右のエアコンを文字なし画像へ分離する。分離実装は未実施。

- **メインコピー**：２台まとめて、お得にキレイ！

- **CTA**：料金・サービスを見る。オレンジの立体ピル形、白い丸の中に右矢印。
