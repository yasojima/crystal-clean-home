# 法人向け清掃：シーンから選ぶパンフレット型ワイヤーフレーム

[ローカルで表示](http://127.0.0.1:8773/home-wireframe/business/)

1案だけのローカル検討用ページです。実行中の8773プレビューを使用します。法人原稿の正本と既存写真を参照し、素材は複製しません。共通ヘッダー・フッターと書体を再利用します。配色は構造を読み取りやすくする仮設定です。

```text
共通ヘッダー
    ↓
ヒーロー：法人向けサービス／店舗・オフィス・共用部
左：既存の紹介文・細枠の相談リンク／右：大きな店舗空間写真
写真を本文幅より広く見せ、角を斜めに切るカバー構図
スマホ：見出し→空間写真→紹介文
    ↓
4つの相談シーン
日常では難しい箇所／定期清掃／衛生面／引き渡し
    ↓
4サービスを写真のサイズ・配置・余白を変えて紹介
エアコン：大きな写真を左／本文を右
床・カーペット：右へ寄せた横長写真／白い本文面を左下へ重ねる
除菌・抗菌：本文と小さなシャワー写真を左／大きな写真を右
引き渡し：左へ寄せた広い空間写真／淡い本文面を右下へ重ねる
    ↓
補足ギャラリー：写真8点／大小・比率に差をつける
厨房、ガラス、トイレ、廊下・階段、洗面所、ベランダなど
    ↓
法人向け清掃のご相談／細枠「お問い合わせはこちら →」
共通フッター
```

| セクション | 役割・この順番の理由 | 当て込んだ既存文章 |
|---|---|---|
| ヒーロー | 法人対応と相談への入口を最初に伝える | `title`、`intro`の全文。店舗・オフィス・共用部の小見出しだけ追加 |
| 相談シーン4件 | 利用者の目的から相談内容を探す中心部分 | エアコンの内部洗浄・定期清掃の文、除菌・抗菌の全文、引き渡し清掃の冒頭文 |
| 写真付き紹介4件 | 写真を大きく扱い、作業内容と空間の雰囲気を伝える。4件の寸法・位置を変えて単調な繰り返しを避ける | 既存`heading`、各`features.title`と`features.text`の全文・対応写真。除菌・抗菌に既存の浴室・シャワー写真を補足 |
| 補足ギャラリー8点 | 主紹介より小さく扱い、幅広い場所への対応を写真で補足する | 既存`gallery`のガラス・サッシ、厨房器具、レンジフード、照明器具、トイレ、廊下・階段、洗面所、ベランダの写真とラベル |
| 末尾相談CTA | 読み終えた利用者が法人相談へ進む | `closing`の全文。相談見出しとボタン文言のみ構造に合わせて追加 |

原稿の所有元は`source/office-cleaning/content.json`。相談シーンの見出しと導線用見出しだけを追加し、既存説明は変更しません。商品価格・購入カード・Before/After・カートは本文に追加しません。共通MENU内の既存機能は保持します。

ヒーローと末尾のCTAは透明背景・1pxの細い枠線を使います。ヒーローは末尾へ移動し、末尾の「お問い合わせはこちら →」は既存の法人相談デモ導線を使用します。本編の末尾CTA削除は維持し、この新案のCTAは検討用ページに限定します。

写真は既存の13種類すべてを参照します。フロアはヒーローと引き渡し、エアコン・カーペット・除菌は各メイン紹介、シャワーは衛生面の補足、残り8種類はギャラリーに配置します。新しい画像の生成・コピーはしません。大きな写真→読み物→大小の補足写真、という強弱でパンフレットの誌面感を作ります。4つの相談シーンも箱型のカードにせず、番号・細い罫線・余白で区切ります。

追加の会社案内参考に合わせ、カバー写真の斜めの切り取り、本文幅から広がる写真、写真の端へ重なる本文面、見出しの太さと罫線を整理しました。PCの相談シーンは左の見出しと右の2×2の本文で構成します。色は青灰色・白の仮トーンに留めます。スマホでは本文を写真の下へ置き、重なりを解消して自然に読める順番を維持します。

生成：`python prototypes/home-wireframe/business/build.py`。`index.html`は生成結果、`wireframe.css`がこの案のレイアウトです。
