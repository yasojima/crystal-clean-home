# 法人向け清掃：写真と日本語で伝えるパンフレット型ワイヤーフレーム

[ローカルで表示](http://127.0.0.1:8773/home-wireframe/business/)

同じローカル1案を更新します。配色は仮設定、共通ヘッダー・フッターと既存写真を参照します。

```text
共通ヘッダー
    ↓
表紙：法人向けサービス
左「店舗・オフィスを、清潔に。」と相談CTA／右：大きな空間写真
PC写真はヘッダー直下から画面右端まで広げる
ユーザーのCanva調整を反映した大きなコピーとCTAを写真へ深く重ねる
ヘッダーを除く画面内に写真・文字・CTA・背面を収める
    ↓
会社紹介：「店舗やオフィスの清潔な／環境づくりをサポート」
ユーザー修正版の紹介文を1段落で表示、最大幅448px
    ↓
こんな清掃をご相談いただけます
既存の円形枠と紺色の背景／01〜04／相談内容を補足した説明
    ↓
紹介誌面1：エアコン（横写真）＋床・カーペット（縦写真）
紹介誌面2：除菌・抗菌（中写真＋洗面所写真）＋引き渡し（横写真）
紹介見出しは最初の写真の左上端へ付ける
主写真は面の88％幅、背面の無地を広く見せる
説明文は最大392pxで自然に折り返す
    ↓
幅広い清掃対応：既存8写真を同じ比率・行と列で整列
    ↓
法人向け清掃のご相談／既存HOMEと同じ青いCTA
共通フッター
```

| セクション | 役割・順番の理由 | 文章と写真の当て込み |
|---|---|---|
| 表紙・会社紹介 | 法人対応を最初に示し、相談への入口と会社の説明につなげる | 既存title・floor写真。表紙コピーは維持。紹介見出しと紹介文は今回のユーザー修正版 |
| 4つの相談シーン | 相談目的から対象や進め方を探せるようにする | 既存4シーンの見出しを使用。既存の対応内容から対象箇所・利用状況・事前確認を補足 |
| 2つの紹介誌面・4サービス | 写真の大小と既存説明で空間と対応内容を伝える | 既存features.title・features.textを全文使用。aircon・carpet・sanitizing・floor。補足写真は指定によりshowerからbasinへ変更、下の文字は削除 |
| 対応箇所8点 | 幅広い場所への対応を一覧で補足する | glass・kitchen・hood・lighting・toilet・hallway・basin・balconyの写真と既存ラベル |
| 末尾相談CTA | 説明を読んだ利用者が法人相談へ進む | 既存closing全文と法人相談デモ導線 |

既存の4説明・末尾文・素材の正本は`source/office-cleaning/content.json`と既存画像です。今回のユーザー修正版の紹介見出し・紹介文と、補足した4シーンの文章は案の生成元`build.py`で管理します。公開原稿は変更しません。本文は強制改行・段落分割をせず、表示幅で自然に折り返します。紹介見出しだけは指定の2行にします。

紹介の全体は最大1040px、本文は14px・最大32em（448px）。4サービスの本文は最大28em（392px）。小さい画面では親幅以内に収まります。相談への補助リンク「相談できる清掃を見る」と、以前削除した補助ラベルは表示しません。

表紙は[ユーザーが調整したCanva](https://www.canva.com/d/Yzn_s8RQ0RDwnaE)の見本を反映します。文言とサイト書体を使い、PCの主コピーを最大110px・行高1.25へ拡大し、2行目を.44em字下げします。PCの写真は右の列枠から外し、表紙の上端から画面右端まで広げ、コピーへ大きく重ねます。既存ヘッダーの実測高を使い、表紙は100svhからその高さを除いた範囲へ収めます。写真は表紙の高さから下端16pxを除く範囲を使い、既存の斜めの切り込みを残します。短いPC画面では横幅とヘッダーを除く高さに合わせてコピーとCTAを縮めます。スマホでは文字・CTAの後に写真を置き、残る高さを写真に配分します。

相談シーンは`c-reason-card`・`c-reasons--navy`等の共通CSSを再利用します。本文を円内の幅へ収め、通常PCは4列、中間幅は2列、スマホは1列。「お客様から選ばれる理由」の装飾見出しや英語のPOINTは追加せず、元の相談見出しと01〜04を使用します。

主紹介の写真は88％幅へ縮め、写真ごとに方向を変えた無地面を広く見せます。素材を増やさずCSS疑似要素で実装します。表紙はその後の追加指示に従って写真を拡大しています。既存12種類の素材を参照し、洗面所だけ紹介と一覧で再利用します。8点の一覧は画像比率3:2で、PC4列・スマホ2列に揃えます。

書体は仕様書「見出しと本文の書体」に従い、見出し・訴求・CTAがZen Kaku Gothic New、本文・写真ラベルがNoto Sans JPです。共通正本`site-typography.css`の変数を使用し、案の明朝指定は除きます。

CTAはHOME「注目のハウスクリーニング」の青い部分と同じ共通クラスを使います。色・文字色・角丸・影・光が流れるホバーを再利用し、矢印は表示しません。末尾はHOMEの画面幅に応じたカード幅へ揃え、通常PC288×64pxを基準とします。表紙のPC CTAはCanva見本から約1割縮め最大420×92px、文字24px、右下角丸46pxへ拡大します。スマホは従来の55px高と書体寸法を使用します。表紙は末尾へ移動し、末尾は既存の法人相談デモを使用します。キーボード操作と動きを減らす設定に対応します。

## 視覚確認したパンフレット実例


Googleで「パンフレット おしゃれ」「会社案内 デザイン」「旅館 パンフレット」を検索し、制作元の実例と写真を確認しました。

- [HOTEL SAILS紹介パンフレット／メディアクト](https://www.mediact.co.jp/works/w-leaflet/article/daito-2/)：大きな室内写真と小さな詳細写真を組み合わせた誌面、読みやすい文字のまとまりを参考にしました。
- [アルコタワー施設紹介パンフレット／GetUp&Design](https://www.worksonpapers.jp/works/%E4%BC%81%E6%A5%AD%E8%AA%98%E8%87%B4%E3%82%92%E7%9B%AE%E7%9A%84%E3%81%A8%E3%81%97%E3%81%9F%E6%96%BD%E8%A8%AD%E3%82%92%E7%B4%B9%E4%BB%8B%E3%81%99%E3%82%8B%E3%83%91%E3%83%B3%E3%83%95%E3%83%AC%E3%83%83/)：写真と文字を共通のグリッドで組み合わせ、大小差を一つの誌面へ収める考え方を参考にしました。

参考先の画像は転載・取り込みません。ユーザー添付の会社案内も構図の参考として扱い、現在の法人清掃写真に適用しています。
