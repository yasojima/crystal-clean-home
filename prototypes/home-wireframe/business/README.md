# 法人向け清掃：写真と日本語で伝えるパンフレット型ワイヤーフレーム

[ローカルで表示](http://127.0.0.1:8773/home-wireframe/business/)

同じローカル1案を更新しています。実行中の8773プレビューを使用し、既存写真と法人原稿の正本を参照します。配色は仮設定です。共通ヘッダー・フッターを再利用し、案の本文内は日本語で構成します。

```text
共通ヘッダー
    ↓
表紙：法人向けサービス
左「店舗・オフィスを、清潔に。」／右：大きな空間写真
斜めの写真端、日本語の明朝見出し、細枠・円形の斜め矢印・明朝文字の相談ボタン
    ↓
会社紹介：既存の訴求見出し／既存の紹介文
    ↓
4つの相談シーン：左の大見出し＋右の段差をつけた2列の索引
日常では難しい箇所／定期清掃／衛生面／引き渡し
    ↓
紹介誌面1：エアコン（大きな横写真）＋床・カーペット（縦写真）
紹介誌面2：除菌・抗菌（中写真＋小写真）＋引き渡し（広い空間写真）
12列の共通グリッド／写真と本文の間に細い罫線
    ↓
補足ギャラリー：既存写真8点
大小を残し、行の下端・ラベル位置・間隔を揃える
    ↓
法人向け清掃のご相談／細枠「お問い合わせはこちら ↗」
共通フッター
```

| セクション | 役割・順番の理由 | 既存文章と写真の当て込み |
|---|---|---|
| 表紙と会社紹介 | 冒頭で法人対応と相談への入口を示し、会社の説明へ進む | `title`、`heading`、`intro`の全文。大きなフロア写真。主訴求「店舗・オフィスを、清潔に。」を追加 |
| 4つの相談シーン | 利用者の目的から相談できる内容を探す中心部分 | エアコンの内部洗浄・定期清掃の文、除菌・抗菌の全文、引き渡し清掃の冒頭文 |
| 2つの紹介誌面・4サービス | 写真を組み合わせて空間と作業内容を伝える。写真の大小と配置を変え、2件を一つの誌面として整理する | 各`features.title`と`features.text`の全文。エアコン、カーペット、除菌、フロアの主写真。衛生面の補足に浴室・シャワー写真 |
| 補足ギャラリー8点 | 主紹介より小さく扱い、幅広い場所への対応を補足する | ガラス・サッシ、厨房器具、レンジフード、照明器具、トイレ、廊下・階段、洗面所、ベランダの既存写真とラベル |
| 末尾相談CTA | 説明を読んだ利用者が法人相談へ進む | `closing`の全文。相談見出しと問い合わせリンクを追加 |

文章の所有元は`source/office-cleaning/content.json`です。既存説明の全文・抜粋を参照し、意味を変えるリライトや本文の強制改行はしません。表紙の「店舗・オフィスを、清潔に。」と紹介部の「清潔な空間へ」は、英語を使わず日本語で訴求する追加指示に合わせた短い見出しです。本文内の英語見出し・飾り文字・写真ラベルは使いません。

写真は既存の13種類をすべて参照します。素材の実体を増やさず、CSSで写真の比率と主題が見える切り取りを調整します。主紹介は12列の共通グリッドに沿い、写真の端・本文の開始位置・罫線を揃えます。大小差は残し、紹介誌面の間には余白と細い区切りを置きます。ギャラリーは主写真より小さくし、写真同士の間隔を詰めて一つのまとまりにします。

表紙とメイン4紹介の写真背面には、無地の面を異なる方向・寸法でずらして重ねます。上左・下右・下左などの重なりを写真ごとに変え、スマホではずれ量を縮めます。面はCSSの疑似要素で作り、追加画像は使いません。2つの仮の無地色を変数として管理します。

相談シーンは左に大きな見出し、右に2列の索引を置きます。大きな淡い番号を本文の左へ揃え、右列を28px下げ、下罫線でまとまりを作ります。タブレットでは見出しを上へ移し、小さいスマホでは1列へ並べます。既存の4つの説明文はそのままです。

日本語の見出しはこの案の範囲だけ明朝体、本文はサイト共通のゴシック体です。番号は小さな補助要素として使います。スマホでは写真の後に本文を置き、床・カーペット写真の右寄せなど、大小差を残して自然に縦へ流します。

「01 / 清掃のご相談」など4つのセクション補助ラベルと、表紙のブランド補助文字・カテゴリラベル・写真の補助キャプションは削除しています。各相談シーンとサービスの小さな番号、写真の内容を示すギャラリーラベルは残します。

相談CTAは透明背景の細枠ボタンです。明朝の文字と46pxの円形アイコンを組み合わせ、340px幅・78px高を基準に余白と押せる範囲を確保します。右下の角だけ22px丸め、円内に1.25pxの細い斜め矢印を置きます。スマホは最大幅を本文内へ収め、高さ70px・円40pxで表示します。ホバー時は円が青灰色になり、矢印が右上へ2px進みます。動きを減らす設定ではトランジションを無効にします。ボタンは表紙と末尾で同じ生成関数・CSSを使います。

表紙は末尾の相談部分へ移動し、末尾は既存の法人相談デモ導線を使用します。本文に価格・購入カード・カート・Before/Afterは追加しません。共通MENU内の既存機能は維持します。

## 視覚確認したパンフレット実例

Googleで「パンフレット おしゃれ」「会社案内 デザイン」「旅館 パンフレット」を検索し、制作元の実例と写真を確認しました。

- [HOTEL SAILS紹介パンフレット／メディアクト](https://www.mediact.co.jp/works/w-leaflet/article/daito-2/)：大きな室内写真と小さな詳細写真を組み合わせた誌面、読みやすい文字のまとまりを参考にしました。
- [アルコタワー施設紹介パンフレット／GetUp&Design](https://www.worksonpapers.jp/works/%E4%BC%81%E6%A5%AD%E8%AA%98%E8%87%B4%E3%82%92%E7%9B%AE%E7%9A%84%E3%81%A8%E3%81%97%E3%81%9F%E6%96%BD%E8%A8%AD%E3%82%92%E7%B4%B9%E4%BB%8B%E3%81%99%E3%82%8B%E3%83%91%E3%83%B3%E3%83%95%E3%83%AC%E3%83%83/)：写真と文字を共通のグリッドで組み合わせ、大小差を一つの誌面へ収める考え方を参考にしました。

参考先の画像は転載・取り込みません。ユーザー添付の会社案内も構図の参考として扱い、現在の法人清掃写真に適用しています。
