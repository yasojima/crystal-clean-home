# HOME 特集バナーの形の比較

現行HOMEを `build.py` から複製したローカルの検討画面。特集枠１か所に、横長バナー・手動スライド・大小バナーの３案を用意する。既存のメニュー・試算・利用案内は追加しない。

```powershell
python prototypes/home-wireframe/build.py
python prototypes/home-wireframe/serve.py --port 8773
```

- [Ａ：横長バナー](http://127.0.0.1:8773/home-wireframe/?pickup=A#wf-pickup)
- [Ｂ：手動スライド](http://127.0.0.1:8773/home-wireframe/?pickup=B#wf-pickup)
- [Ｃ：大小バナー](http://127.0.0.1:8773/home-wireframe/?pickup=C#wf-pickup)

比較ボタンで形を切り替え、比較表示を隠す／戻すことができる。固定見積もりは初期状態で隠し、必要に応じて表示する。旧比較URLのアンカーは特集枠へ移動する。

特集は８カテゴリの直前に仮配置する。Ａは複数台割引の横長バナー１枚、Ｂは複数台割引・お手入れ・引越しの３訴求を手動で送るスライド、Ｃは主バナーと２枚の補助バナー。スライドは前後・直接選択・左右キーで操作し、自動送りしない。

文言は形を判断するためのラフ。既存配信素材を参照し、画像は複製しない。エアコンの割引差額は既存 `CCH_CART_CATALOGUE` の壁掛け・お掃除機能なしの１台価格と２台以上価格から計算し、税込・機種・数量条件を併記する。架空の期間やクーポン、営業実績は作らない。各バナーから既存のサービス詳細ページへ移動する。

`build.py` が文言・配置の正本、`index.html` は生成成果物。既存８カテゴリ・２バナー・理由・お悩み・動画・共通ヘッダー／フッターのマークアップを保持する。公開HOMEへの採用・反映は未決定。

参考：[おそうじ本舗のピックアップ導線](https://www.osoujihonpo.com/index.html)。サービスに関心を向ける役割を参考にし、新規の形状は独自のHTML／CSSで組む。
