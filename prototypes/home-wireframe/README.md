# HOME ワイヤーフレーム比較

現行 `source/site/index.html` を複製し、追加する３セクションに各３案を用意したローカル検討画面。公開HOMEの置換・公開は含めない。

```powershell
python prototypes/home-wireframe/build.py
python prototypes/home-wireframe/serve.py --port 8773
```

- [比較画面](http://127.0.0.1:8773/home-wireframe/)
- [全体Ａ案](http://127.0.0.1:8773/home-wireframe/?preset=A#wf-choose)
- [全体Ｂ案](http://127.0.0.1:8773/home-wireframe/?preset=B#wf-choose)
- [全体Ｃ案](http://127.0.0.1:8773/home-wireframe/?preset=C#wf-choose)

各セクションのボタンで別々の案を組み合わせられる。選択はURLの `choose`・`budget`・`flow` に反映する。「比較表示を隠す」で検討用の説明・切替を隠し、完成時の並びを確認できる。固定見積もりUIは検討中の本文を覆わないよう初期状態で隠し、専用ボタンで元の表示に切り替えられる。

| 追加する役割 | Ａ案 | Ｂ案 | Ｃ案 |
|---|---|---|---|
| メニュー選び | 大小の読み物 | 番号付き横一覧 | 展開式の案内 |
| 予算の試算 | 選択タイル＋合計帯 | 一覧＋明細 | 展開式＋結果パネル |
| 訪問までの流れ | 横につながる４段階 | 交互のタイムライン | お客様とスタッフの２面 |

既存の動画枠・８カテゴリ・２バナー・選ばれる理由・お悩み・下の８カテゴリ・共通ヘッダー／フッターを保持する。新しい読み物を理由とお悩みの間、試算と訪問案内をお悩みと下の８カテゴリの間に追加する。

CSS・画像・商品データ・料金計算は現行サイトを参照し、画像ファイルを複製しない。`build.py` が文言と構造の正本、`index.html` は再生成できる確認用成果物。試算は代表３メニューに限定し、既存 `CCHCartCore` の複数台割引・税込合計を再利用する。選択はメモリ内だけに保持し、既存カートを書き換えない。`/quick_cart/` は全メニューの選択入口で、この画面の数量は引き継がない旨を比較画面に表示する。

送信から訪問までは予定する導線の構成案。現在の既存見積もり機能の範囲は入力・確認までで、送信・予約確定は接続していない。確約する日時・追加料金条件・作業保証・架空の評価は追加していない。

参考サイトから学んだ「サービス案内から料金と見積もりへつなぐ」役割を使い、新規の９レイアウトは独自のHTML／CSSで組む。参考サイトの新規セクション形状や販促画像はコピーしない。
