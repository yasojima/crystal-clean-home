# HOME お知らせ・特集バナーの比較

現行HOMEを `build.py` から複製したローカルの検討画面。既存バナーを維持し、「お悩み・ご要望別」と末尾の８項目の間に「最新のお知らせ」の３案を追加する。特集バナーの比較３案も保持する。

```powershell
python prototypes/home-wireframe/build.py
python prototypes/home-wireframe/serve.py --port 8773
```

- [お知らせＡ：日付・見出しの一覧](http://127.0.0.1:8773/home-wireframe/?news=A#wf-news)
- [お知らせＢ：注目１件＋ほか２件](http://127.0.0.1:8773/home-wireframe/?news=B#wf-news)
- [お知らせＣ：３枚のカード](http://127.0.0.1:8773/home-wireframe/?news=C#wf-news)

お知らせは `build.py` の `NEWS` で日付・分類・見出し・短文・本文を管理する。全案・一覧・本文で同じ３件を表示し、仮原稿・掲載日未確定と明示する。見出しから本文、「お知らせ一覧を見る」から一覧を比較用ダイアログで開く。閉じる・Escape・本文から一覧へ戻る操作ができる。公開用の記事ページ・投稿管理機能は作成しない。

Ａは３行の一覧、Ｂは注目１件と補足２件、Ｃは３カード。スマホでは日付・分類と見出しを２段に分け、Ｂ／Ｃは縦に並べる。境界の曲線は既存共通CSSを再利用する。

比較ボタンで形を切り替え、比較表示を隠す／戻すことができる。固定見積もりは初期状態で隠し、必要に応じて表示する。旧比較URLのアンカーは特集枠へ移動する。

特集は８カテゴリの直前に仮配置する。Ａは複数台割引の横長バナー１枚、Ｂは複数台割引・お手入れ・引越しの３訴求を手動で送るスライド、Ｃは主バナーと２枚の補助バナー。スライドは前後・直接選択・左右キーで操作し、自動送りしない。

文言は形を判断するためのラフ。既存配信素材を参照し、画像は複製しない。エアコンの割引差額は既存 `CCH_CART_CATALOGUE` の壁掛け・お掃除機能なしの１台価格と２台以上価格から計算し、税込・機種・数量条件を併記する。架空の期間やクーポン、営業実績は作らない。各バナーから既存のサービス詳細ページへ移動する。

`build.py` が文言・配置の正本、`index.html` は生成成果物。`news=A/B/C` と `pickup=A/B/C` は独立して切り替える。既存８カテゴリ・２バナー・理由・お悩み・動画・共通ヘッダー／フッターのマークアップを保持する。公開HOMEへの採用・反映は未決定。

参考：[おそうじ本舗のピックアップ導線](https://www.osoujihonpo.com/index.html)。サービスに関心を向ける役割を参考にし、新規の形状は独自のHTML／CSSで組む。
